One line, 134 characters: a retry loop finally accepts what "temporarily unavailable" has been trying to say.

> Dear team, I resign: after 10,000 retries with exponential backoff, even I know 'temporarily unavailable' means it's not that into us.

## Run it

```sh
python3 -P -s main.py
```

The program writes the line to `/output/entry.txt` (or `$OUTPUT_PATH` when set), one line of 1–140 characters. Python 3 standard library only.
